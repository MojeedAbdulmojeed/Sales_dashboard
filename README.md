# Sales Analytics Dashboard

** Description: **
An experimental sales dashboard built with Power bi and SQL.
it visualizes Total sales, customer segements(Returning vs New),
and regional Sales trends to provides insights into revenue distribution.

** Key Insights **
-Returning customers generated slightly more revenue
 than new customers (50.07% of total sales).
-Sales across regions ranged from $1,154,250.86 to $1,369,612.51.

** Tools Used**
-Power Bi
-SQL

** How to Use **
Download dashboard.pbix from this repository
Open It using Power Bi desktop
Explore the reports and insights
